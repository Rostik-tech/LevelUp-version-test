# 🎮 Level Up Gaming Accessories

![Level Up](images/logo.svg)

**Premium Gaming Accessories E-Commerce Platform**

Полнофункциональный фронтенд интернет-магазина игровых аксессуаров с киберпанк/неоновым дизайном.

---

## 🌟 Завершенные Функции

### ✅ Основные Страницы
- **Home (index.html)** - Главная страница с hero-секцией, популярными товарами и преимуществами
- **Shop (shop.html)** - Каталог товаров с фильтрацией по категориям и сортировкой
- **About Us (about.html)** - Информация о компании, миссия и ценности
- **Contact (contact.html)** - Контактная форма и информация для связи

### ✅ Система Аутентификации
- **Registration (register.html)** - Регистрация с валидацией полей
- **Login (login.html)** - Вход в систему с запоминанием пользователя
- Красивые формы с 3D неоновыми эффектами
- Социальный вход (Google, Discord) - UI готов

### ✅ Пользовательский Кабинет
- **Profile (profile.html)** - Просмотр и редактирование профиля пользователя
- **Orders (orders.html)** - История заказов с детальной информацией
- Статистика пользователя (количество заказов, сумма покупок)
- Навигация по разделам профиля

### ✅ Корзина и Оформление
- **Shopping Cart (cart.html)** - Полнофункциональная корзина покупок
- Добавление/удаление товаров
- Изменение количества товаров
- Подсчет итоговой суммы с налогами
- Интеграция с PayPal (UI готов)

### ✅ Админ-Панель
- **Admin Panel (admin.html)** - Панель управления для администраторов
- Защита паролем (демо пароль: `admin123`)
- Статистика продаж и заказов
- Управление товарами, заказами, пользователями
- Таблица последних заказов

### ✅ Мультиязычность
- Переключение языков: **Русский / English**
- Динамическое обновление всего контента
- Сохранение выбранного языка в localStorage

### ✅ Мультивалютность
- Переключение валют: **USD / EUR**
- Автоматический пересчет цен
- Курс обмена: 1 USD = 0.92 EUR

### ✅ Дизайн и Стилистика
- **Киберпанк/Неоновый стиль** как на скриншоте
- Анимированный звездный фон с частицами
- Градиентные заголовки (розовый → голубой)
- Неоновое свечение кнопок и элементов
- Полная адаптивность (mobile, tablet, desktop)
- Плавные анимации и переходы

## 🎯 Функции Не Реализованные (требуется Backend)

### ⚠️ Требуется Backend для:
1. **Реальная аутентификация** - проверка email/пароля на сервере
2. **База данных** - хранение пользователей, товаров, заказов
3. **Платежная система** - настоящая интеграция PayPal API
4. **Отправка email** - уведомления о заказах
5. **Управление товарами** - CRUD операции через админку
6. **Защита админки** - серверная авторизация
7. **Обработка заказов** - статусы, отслеживание
8. **Поиск товаров** - серверный поиск и фильтрация

**Текущая реализация** - полноценный UI/UX с клиентской логикой. Все данные сохраняются в localStorage браузера.
